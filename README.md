# Thread Pool

Курсовая работа по дисциплине «Многопоточное и асинхронное программирование на Java».

## Реализовано

* собственный пул потоков;
* corePoolSize и maxPoolSize;
* keepAliveTime;
* ограничение размера очередей;
* minSpareThreads;
* распределение задач по алгоритму Round Robin;
* обработка перегрузки через RejectedTaskHandler;
* логирование основных событий работы пула.

## Структура проекта

* CustomThreadPool.java — реализация пула потоков;
* Worker.java — рабочий поток;
* CustomThreadFactory.java — создание потоков;
* AbortRejectedTaskHandler.java — обработка перегрузки;
* Main.java — демонстрация работы.

## Особенности реализации

Для балансировки задач используется алгоритм Round Robin.

При заполнении всех очередей и достижении maxPoolSize новые задачи отклоняются. Такой подход позволяет избежать бесконтрольного роста потребления памяти, однако часть задач может быть потеряна при высокой нагрузке.

По сравнению со стандартным ThreadPoolExecutor реализованное решение содержит меньше возможностей, но позволяет лучше понять принципы работы пулов потоков.

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Использовать JDK 17.
3. Запустить класс Main.
